# JourneyStats-for-Omsi
A statistics and graphing tool for OMSI 2, powered by OpenOmsi — visualize, analyze, and export public transport data.
JourneyStats for OMSI
Made by Stitus

Early Beta Build 0.03

A lightweight application for extracting statistics from OMSI and turning them into clear, readable graphs.
The project aims to make it easier to explore, visualize, and analyze data collected from OMSI.
Goal is to make realistic looking statistics used by profesionals for planning of public transport.

Features

- 📊 Statistics visualization — turn OMSI statistics into graphs.
- 📈 Graph generation — visualize data in a more readable format.
- 📤 Statistics export — extract and export statistics for further use, multiple export options for Instagram, PNG, clear text or .xlsx
- 🚌 OMSI-focused — designed specifically for working with OMSI-related data, theme inspired by Openomsi launcher.

Features and functionality may change as development continues.
